## 🎬 Шортсы

Раз в несколько дней выходит новый ролик — баги, мифы и разводы из мира IT, а живой код из роликов попадает сюда, в демки.

| Рубрика | Что внутри |
| --- | --- |
| 🔎 Баг-детектив | Реальные баги с неочевидной причиной: песня, ронявшая ноутбуки; крик в дата-центре |
| 🕵️ Развод-детектив | Железо, которое тебе врёт: кабель с вай-фаем, флешки-пустышки |
| 💥 Миф | Ломаем мифы разработчиков своими замерами |
| 📚 Ликбез | Сложное просто: WebGL, Web Audio, звук — это числа |
| 🤷 Не баг, а фича | Странности, которые так задуманы |
| 🛠 Сделано в HellCord | Проекты участников сервера |
